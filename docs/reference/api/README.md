# API documentation

Use this folder when you want to call Apex Log Insights from code. It documents public interfaces, expected inputs and outputs, and runnable examples.

## Start here

- [Core API](core.md) explains how to parse an Apex debug log and generate a structured report from TypeScript or JavaScript.
- [Report schema](../report-schema.md) defines the report fields returned by the core library and other interfaces.
- [Core package README](../../../packages/core/README.md) covers installation, exports, and package-level development.

## What belongs here

Add documentation here for a public programming interface. Keep implementation details in the source code or [architecture guide](../../development/architecture.md). When an API changes, update its reference, examples, and the [changelog](../../../CHANGELOG.md) in the same change.
