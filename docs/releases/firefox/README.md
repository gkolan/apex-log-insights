# Firefox release packages

This folder contains versioned `.xpi` builds for Mozilla Firefox and matching `firefox-source-v*.zip` reviewer archives. Use the Firefox store for normal installation. The 1.2.0 candidate here is unsigned and is intended for submission or temporary development loading, not normal persistent installation.

Use the newest version unless you are reproducing behavior from an earlier release. For installation, development loading, and package verification, follow the [browser-extension guide](../../../packages/browser-ext/README.md).

Create or replace packages only through the [release process](../../development/releasing.md). Do not modify archive contents manually.

Upload the XPI as the add-on package and attach the matching source ZIP for reviewer access. The source archive contains its own environment and build instructions.
