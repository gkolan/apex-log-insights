# Edge release packages

This folder contains versioned `.zip` packages for Microsoft Edge. Each archive is a complete extension build produced by the project release process.

Use the newest version unless you are reproducing behavior from an earlier release. For store installation, development loading, and package verification, follow the [browser-extension guide](../../../packages/browser-ext/README.md).

Create or replace packages only through the [release process](../../development/releasing.md). Do not modify archive contents manually.
